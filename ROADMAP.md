# Project Hydra Roadmap — Closed

## Outcome

Project Hydra was discontinued before its planned v1.0 implementation. Its scope has been consolidated into the Cerberus Desktop & Workflow Environment.

## Completed

- [x] Create the Hydra repository.
- [x] Document the original Windows 10 dual-monitor concept.
- [x] Define the original charter and engineering principles.
- [x] Reassess Hydra after the Cerberus operating-system and platform decisions.
- [x] Transfer ownership of multi-monitor workspace design to Cerberus.
- [x] Preserve Hermes as the separate Windows 11 laptop automation project.
- [x] Close the standalone Hydra roadmap.

## Cancelled as Hydra work

The following items will not be implemented in this repository:

- Windows 10 display inventory automation
- PowerShell-based monitor discovery
- Windows application placement and sizing
- Windows workspace profiles
- Hydra v1.0 testing and release
- A standalone Hydra-to-Cerberus migration

Their Fedora/KDE equivalents will be designed and tracked in [Project Cerberus](https://github.com/scott-renny/project-cerberus-build).

## Final state

- **Status:** Discontinued
- **Implementation:** Not released
- **Successor:** Project Cerberus
- **Successor workstream:** Desktop & Workflow Environment
- **Repository purpose:** Historical decision record
